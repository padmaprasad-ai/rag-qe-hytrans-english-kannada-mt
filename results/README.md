\# Results



This folder contains final reported result summaries for the RAG-QE-HyTrans English–Kannada machine translation experiments.



The files in this folder are lightweight summaries intended for review and reproducibility documentation. Large generated artifacts such as translation CSV files, sentence-level score files, model checkpoints, LoRA adapters, FAISS indices, and runtime logs are not stored in the repository.



\## Files



| File | Description |

|---|---|

| `final\_5k\_results.md` | Final results and interpretation for the 5K English–Kannada experiment. |

| `final\_50k\_results.md` | Final results and interpretation for the 50K English–Kannada experiment. |

\## Notes



The test-set sensitivity result at threshold 0.99 is included in the detailed 50K result file for diagnostic analysis, but it is not treated as the main methodologically valid RAG result.



The final reported results can be regenerated by following the pipeline in the main repository `README.md`.
