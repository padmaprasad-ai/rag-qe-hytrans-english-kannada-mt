\# Data and Code Availability



The source code, configuration files, result summaries, figures, and reproduction instructions for the RAG-QE-HyTrans framework are publicly available at:



https://github.com/padmaprasad-ai/rag-qe-hytrans-english-kannada-mt



The raw dataset is not redistributed in this repository. The experiments use the Kannada (`kn`) subset of the AI4Bharat Samanantar corpus available through Hugging Face. Scripts are provided to download and preprocess the dataset.



Large generated artifacts are excluded from the repository, including:



\- raw dataset files

\- cleaned train/validation/test splits

\- model checkpoints

\- LoRA adapter weights

\- FAISS index files

\- sentence-level translation outputs



These artifacts can be regenerated by following the reproduction pipeline described in the repository README.



The original cloud GPU pod used for experimentation was terminated after completion. However, the repository preserves the experiment source scripts, configuration file, final result summaries, figures, and reproducibility documentation.
