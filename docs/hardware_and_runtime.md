\# Hardware and Runtime Notes



The RAG-QE-HyTrans experiments were executed in a cloud GPU environment.



\## Original Hardware



The 50K LoRA fine-tuning experiment was run on an NVIDIA A40 GPU.



The original cloud GPU pod was terminated after completion of the experiments. Therefore, large intermediate runtime artifacts such as model checkpoints, LoRA adapter weights, FAISS indices, and full sentence-level translation outputs are not preserved in the repository.



\## Reproducibility Scope



This repository preserves:



\- original source code

\- configuration files

\- final reported result summaries

\- paper figures

\- reproducibility checklist

\- data and code availability documentation



The repository does not include:



\- raw dataset files

\- processed train/validation/test split files

\- model checkpoints

\- LoRA adapter weights

\- FAISS index files

\- generated translation CSV files

\- runtime logs from the terminated cloud pod



These artifacts can be regenerated by rerunning the scripts.



\## Practical Runtime Note



Running the full 50K pipeline on CPU is not recommended. The baseline translation step is slow on CPU, and LoRA fine-tuning requires a CUDA-enabled GPU for practical execution.



Recommended hardware for full reproduction:



\- NVIDIA GPU with CUDA support

\- At least 16 GB GPU memory

\- 32 GB or more system RAM

\- Stable internet connection for downloading Hugging Face models and datasets



\## Original 50K LoRA Runtime



The 50K LoRA fine-tuning stage used:



\- Base model: `facebook/nllb-200-distilled-600M`

\- Training records: 39,642

\- Validation records used during training: 1,000

\- Epochs: 2

\- LoRA rank: 8

\- LoRA alpha: 16

\- LoRA dropout: 0.05

\- Trainable parameters: approximately 1.18 million

\- Runtime: approximately 13,338 seconds, about 3.70 hours, on NVIDIA A40 GPU



\## Recommendation for Reviewers



One can inspect the code, configuration files, final result summaries, and figures directly from the repository. Full regeneration of results should be performed in a GPU-enabled environment.
